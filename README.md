# FvS ONE – Registration Form Clone
A pixel-focused rebuild of the Flossbach von Storch ONE customer registration / investor-profiling form, built from scratch with plain HTML, CSS and JavaScript.  The original lives at flossbachvonstorch.de/de/registrierung/#/guest/one/profiler/milestones?workflow=personal — a multi-step, hash-routed SPA that walks a user through their personal data and an 11-question investor profile before account creation and identity verification. This project reproduces that experience: the layout, the step-by-step wizard, the validation behaviour and the submission flow.
